# Product Requirements Document (PRD)
## Project: E-Commerce Store (toko.naufal.me)

### 1. Objective
Membangun platform toko online modern dengan performa tinggi, UI responsif, manajemen produk, dan integrasi payment gateway lokal (Midtrans / QRIS).

### 2. Core Features
- **Katalog Produk:** Filter kategori, pencarian real-time, varian harga & stok.
- **Keranjang Belanja:** State persistent (Zustand/Local Storage) dengan checkout instan.
- **Payment Gateway:** QRIS, Virtual Account (BCA, Mandiri, BNI), E-Wallet.
- **Dashboard Admin:** Tambah produk, pantau transaksi, ubah status pesanan.
